## The 7 Basic Questions to Ask When You First Get a Dataset

### 1. How big is the data?
- Use `df.shape` to instantly see the number of rows and columns.
- Knowing the size upfront helps you decide how to approach the rest of your analysis (e.g., a huge dataset may need sampling strategies).

### 2. What does the data look like?
- Avoid just using `df.head()` alone — it only shows the top rows, which can introduce **bias** if the data has any inherent ordering (e.g., sorted data).
- **Better approach:** use `df.sample(n)` (e.g., `df.sample(5)`) to pull random rows. This gives a more representative first impression and avoids forming wrong assumptions about the dataset.

### 3. What are the data types of each column?
- Use `df.info()` — this shows:
  - Number of non-null values per column
  - Data type of each column
  - Total memory usage of the dataframe
- Example from Titanic dataset: 12 columns total — a mix of **numerical** and **categorical** (`object`) columns.
- **Tip:** Watch for numerical columns unnecessarily stored as `float` when they could be `int` (e.g., whole numbers stored with decimals). Converting such columns to a smaller/more appropriate dtype reduces memory usage and can speed up algorithms on large datasets.

### 4. Are there missing values?
- Missing values are a major pain point — deciding how to handle/fill them is a key later step.
- **Quick visual check:** scan `df.info()` or the dataframe for non-null counts less than the total row count.
- **Better approach for large datasets:** use `df.isnull().sum()` — returns a clean series showing missing value counts per column.
- Example: Titanic dataset had significant missing values in the **Cabin** and **Age** columns.
- This tells you in advance which columns need imputation and which might need to be dropped.

### 5. What does the data look like mathematically? (Numerical summary)
- Use `df.describe()` — gives high-level statistics for all numerical columns:
  - Count, Mean, Standard Deviation, Min, 25th percentile, 50th percentile (median), 75th percentile, Max
- Example insights from Titanic:
  - `PassengerId` is just an index — not useful for analysis.
  - Mean age ≈ 30, standard deviation ≈ 13.
  - 25% of passengers were age ≤ 20, 50% ≤ 28, 75% ≤ 38.
- This step can reveal anomalies or oddities in numerical columns early on.

### 6. Are there duplicate values?
- Duplicate rows can distort/mislead your ML algorithm if left untreated.
- **Best practice:** always check for duplicates before doing any further analysis.
- Use `df.duplicated().sum()` — tells you exactly how many duplicate rows exist.
- If duplicates exist (e.g., a result of 55 meaning 55 duplicate rows), remove them using `df.drop_duplicates()`.
- In the Titanic dataset used here, all rows were unique — no duplicates.

### 7. Is there correlation between columns?
- Correlation tells you whether one column's increase/decrease affects another column.
- Important because not all input columns are actually useful for prediction — irrelevant columns should be identified and removed.
- Use `df.corr()` to get a correlation matrix between all numerical columns.
- Correlation values range from **-1 to +1**:
  - **+1** → perfectly positively correlated (as one increases, so does the other)
  - **-1** → perfectly negatively correlated (as one increases, the other decreases)
  - **0** → no correlation at all
- Example insights from Titanic (correlation with `Survived`):
  - `Fare` had a positive correlation with `Survived` (~0.2) — passengers who paid more had a slightly higher survival chance.
  - `Pclass` had a strong negative correlation with `Survived` — as passenger class number increased (i.e., cheaper class), survival chance decreased. This matches historical fact: 3rd class had the highest casualties.
  - `PassengerId` had ~0 correlation with `Survived` — confirming it's a useless column for prediction.

## Key Takeaway
Before diving into detailed EDA (univariate/multivariate analysis) or modeling, always run through this checklist first to build initial intuition about a new dataset:

| # | Question | Pandas Function |
|---|----------|-----------------|
| 1 | How big is the data? | `df.shape` |
| 2 | What does it look like? | `df.sample(n)` |
| 3 | What are the column data types? | `df.info()` |
| 4 | Are there missing values? | `df.isnull().sum()` |
| 5 | What's the numerical summary? | `df.describe()` |
| 6 | Are there duplicates? | `df.duplicated().sum()` |
| 7 | Is there correlation between columns? | `df.corr()` |
