
# Exploratory Data Analysis (EDA): Univariate Analysis

Notes based on a tutorial covering univariate analysis using the Titanic dataset.

## What is EDA?

Exploratory Data Analysis is about **understanding data deeply** before modeling. There are three main approaches:

- **Univariate analysis** — studying one column/variable at a time
- **Bivariate analysis** — studying two columns together
- **Multivariate analysis** — studying more than two columns together

This note focuses on **univariate analysis**.

## Types of Data

Every column in a dataset is either:

1. **Numerical data** — represented by numbers (e.g., height, weight, age, phone price, battery capacity)
2. **Categorical data** — represented by categories/labels (e.g., country, nationality, state, gender, college, engineering branch)

The first step in univariate analysis is always: **"Is this column numerical or categorical?"** The analysis approach depends on the answer.

## Analyzing Categorical Columns

### 1. Count Plot
The most basic and useful technique — shows the **frequency of each category**.

```python
import seaborn as sns
sns.countplot(data=df, x='Survived')
```

Also can be done manually:
```python
df['Survived'].value_counts()
```

**Findings from Titanic data:**
- Out of 891 passengers, ~549 died and ~342 survived
- Most passengers traveled in **Class 3**, fewer in Class 1, fewest in Class 2
- More people boarded from **Southampton**, fewest from **Queenstown**

### 2. Pie Chart
Same idea as count plot, but shows **percentages** instead of raw counts. Useful when you want proportion info.

```python
df['Survived'].value_counts().plot.pie(autopct='%1.1f%%')
```

**Findings:**
- ~61.1% did not survive, ~38.9% survived
- Class distribution: ~55% in Class 3, ~20% in Class 2, ~24% in Class 1
- Gender: roughly 65% male, ~36% female (approx., per the video's numbers)

## Analyzing Numerical Columns

Numerical data is continuous, so raw frequency counts aren't as useful. Instead, focus on:
- Minimum, maximum, mean values
- **Distribution shape** (how values are spread out)

### 1. Histogram
Divides the numerical range into **bins** and shows how many values fall into each bin.

```python
import matplotlib.pyplot as plt
plt.hist(df['Age'])
```

- The number of `bins` can be adjusted:
  - Too many bins → very granular, jagged bars
  - Too few bins → very smooth/simplified bars
- This choice is a modeling decision — no single "correct" number.

**Finding:** Titanic age distribution — few very young and very old passengers, most passengers fall in the middle age range (roughly 20s–40s).

### 2. Distribution Plot (KDE)
An improved/smoothed version of the histogram.

```python
sns.distplot(df['Fare'])
```

- The smooth curve is called **KDE (Kernel Density Estimation)**
- This curve approximates the **PDF (Probability Density Function)**
- X-axis = value, Y-axis = probability/density
- Used to estimate the probability of a value falling within a range (e.g., probability that a randomly picked passenger's age is around a certain value)
- This concept becomes especially useful later in bivariate/multivariate analysis

### 3. Box Plot
Gives a **five-number summary**:

1. **Minimum** (calculated) = Q1 − 1.5 × IQR
2. **Q1 (25th percentile)** — 25% of data is below this value
3. **Median (50th percentile)**
4. **Q3 (75th percentile)** — 75% of data is below this value
5. **Maximum** (calculated) = Q3 + 1.5 × IQR

Where **IQR (Interquartile Range) = Q3 − Q1**

- Values outside the calculated min/max range are flagged as **potential outliers**
- Box plots are a quick, easy way to spot and later handle/eliminate outliers

**Finding on Fare column:** Strong left-shift — most fares are low, but there are significant outliers (e.g., a fare of $500 that is far above the rest).

### Additional Numerical Summaries
Simple descriptive stats can also be pulled directly:

```python
df['Age'].min()
df['Age'].max()
df['Age'].mean()
```

### Skewness
Distribution plots also reveal whether data is **skewed**:

- **Symmetrical / Normal distribution** — data centered evenly (e.g., a classic bell curve)
- **Right-skewed (positive skew)** — many low values, few high values (e.g., salary distribution — most people earn less, few earn a lot)
- **Left-skewed (negative skew)** — many high values, few low values (e.g., exam scores where most students score well, few score poorly)

Skewness can also be checked programmatically:
```python
df['Fare'].skew()
```
- ~0 → symmetrical
- Positive → right-skewed
- Negative → left-skewed

## Key Takeaway
For any dataset, univariate analysis means going column by column and asking:
1. Is it numerical or categorical?
2. Based on that, apply the right plot (count plot/pie chart for categorical; histogram/distplot/box plot for numerical)
3. Extract descriptive stats (counts, percentages, min/max/mean, distribution shape, outliers)

**Suggested practice:** Pick any dataset of personal interest (sports, movies, etc.) and try running univariate analysis on it independently.
