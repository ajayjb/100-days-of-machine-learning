## 3 Types of Column Combinations
When working with two columns, three combinations are possible:
1. **Numerical – Numerical**
2. **Numerical – Categorical**
3. **Categorical – Categorical**

---

## 1. Numerical – Numerical Analysis

### Scatter Plot
Using the Tips dataset, `total_bill` vs `tip`:

```python
sns.scatterplot(data=tips, x='total_bill', y='tip')
```

- Each dot represents one customer
- As total_bill increases, tip increases roughly linearly

### Multivariate Extension (hue, style, size)
Extra hidden parameters on a scatter plot let you do multivariate analysis:

```python
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', style='smoker', size='size')
```

- **hue='sex'** → color-codes gender (blue = female, orange = male)
- **style='smoker'** → shape-codes smoker/non-smoker (cross/circle)
- **size='size'** → dot size reflects how many people were in the group

→ A single graph can convey 5 pieces of information (total_bill, tip, sex, smoker, size). This is an example of Multivariate Analysis.

## 2. Numerical – Categorical Analysis

### Bar Plot
Using the Titanic dataset, average age by pclass:

```python
sns.barplot(data=titanic, x='pclass', y='age')
```
- Pclass 1 has the highest average age (~38), decreasing progressively
- The black bar = Confidence Interval (covered in the statistics playlist)

Fare by pclass:
```python
sns.barplot(data=titanic, x='pclass', y='fare')
```
- Pclass 1 fare is $80+, while Pclass 2 and 3 don't differ much

Multivariate with hue:
```python
sns.barplot(data=titanic, x='pclass', y='fare', hue='sex')
```
- In every class, women's average fare is higher than men's
- Same pattern holds for age

### Box Plot
```python
sns.boxplot(data=titanic, x='sex', y='age')
```
- More outliers appear among men

With hue:
```python
sns.boxplot(data=titanic, x='sex', y='age', hue='survived')
```
- Among surviving men, younger ones are more common
- Among surviving women, older ones are more common

### Dist Plot (PDF)
Comparing the age PDF of those who died vs. those who survived:

```python
died = titanic[titanic['survived'] == 0]
sns.distplot(died['age'], hist=False)

survived = titanic[titanic['survived'] == 1]
sns.distplot(survived['age'], hist=False)
```

**Observations:**
- At very young ages (children), survival probability is higher than death probability (children were prioritized for rescue)
- Between ages 15-30, death probability is higher
- At older ages, survival probability drops (less agility/mobility)

## 3. Categorical – Categorical Analysis

### Crosstab + Heatmap
```python
pd.crosstab(titanic['pclass'], titanic['survived'])
```

| Pclass | Died | Survived |
|---|---|---|
| 1 | 80 | 136 |
| 2 | 97 | 87 |
| 3 | 372 | 119 |

Visualize with a heatmap (useful for larger grids):
```python
sns.heatmap(pd.crosstab(titanic['pclass'], titanic['survived']))
```

### Percentage-based Analysis (Groupby)
Using percentages instead of raw counts gives a better comparison:

```python
(titanic.groupby('survived').mean()['pclass']) * 100
```

**Survival rate by pclass:**
- Pclass 1: 62%
- Pclass 2: 47%
- Pclass 3: 24%

**Survival rate by sex:**
- Female: 74%
- Male: 18%

**Survival rate by embarked:**
- Cherbourg: 55%
- Queenstown: 38%
- Southampton: 33%

*Possible reason: more women and more Pclass 1 passengers boarded at Cherbourg.*

> This is how EDA works — one graph leads to a question/story, and that story leads to further investigation (like detective work).

### Cluster Map (Dendrogram)
```python
sns.clustermap(pd.crosstab(titanic['parch'], titanic['survived']))
```
- Shows hierarchical closeness/similarity between values (dendrogram)
- Reveals which groups behave similarly to each other

## 4. Pair Plot (Multiple Numerical Columns)

Using the Iris dataset:
```python
sns.pairplot(iris)
```
- Automatically generates scatter plots for every pair of numerical columns
- The diagonal (a column against itself) shows a histogram

Multivariate with hue:
```python
sns.pairplot(iris, hue='species')
```
- The three species (setosa, versicolor, virginica) are color-coded
- Pairs like petal width vs. sepal length make it easy to distinguish species

---

## 5. Line Plot (Time-based Data)

When the x-axis is time-based (year, month, date), use a line plot. Flights dataset:

```python
new_df = flights.groupby('year').sum().reset_index()
sns.lineplot(data=new_df, x='year', y='passengers')
```
- Passenger numbers grew almost linearly between 1949-1960

### Pivot Table + Heatmap
```python
pivot = flights.pivot_table(values='passengers', index='month', columns='year')
sns.heatmap(pivot)
```
- Lighter shade = more passengers
- Summer months (June-August) consistently show the most passengers
- Passenger numbers increased year over year

### Cluster Map
```python
sns.clustermap(pivot)
```
- January and February behave similarly
- July-August (summer) fall in the same group
- 1959 and 1960 behave similarly
