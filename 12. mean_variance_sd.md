# Mean, Variance & Standard Deviation — ML Beginner Notes

## 1. Why These Three Matter in ML

Before you train any model, you need to describe your data in numbers. Mean, variance, and standard deviation are the three most basic "descriptive statistics" — they answer:

| Question | Answered by |
|---|---|
| Where is the data centered? | **Mean** |
| How far is one point from the center? | **Deviation** |
| What's the average spread (squared)? | **Variance** |
| What's the typical spread (same units as data)? | **Standard Deviation** |

These show up everywhere in ML: feature scaling (standardization), understanding outliers, checking if a feature is useful, evaluating model errors, and more.

---

## 2. Mean (μ)

The mean is the average of a set of values — the "center of gravity" of the data.

**Formula (population mean):**

$$\mu = \frac{\sum_{i=1}^{N} x_i}{N}$$

- μ (mu) = population mean
- xᵢ = an individual value
- N = number of values
- Σ = "sum of"

**Example**

Data: `6, 7, 8, 9, 10`

$$\mu = \frac{6+7+8+9+10}{5} = \frac{40}{5} = 8$$

**Mean = 8**

**In Pandas:**
```python
df["CGPA"].mean()

# grouped mean — compare average CGPA by placement status
df.groupby("Placement")["CGPA"].mean()
```

**Remember:** Mean = "Where is the center of the data?"

---

## 3. Deviation (xᵢ − μ)

A deviation is how far **one** value is from the mean. This is a building block for variance — it is *not* the standard deviation itself.

**Formula:**

$$x_i - \mu$$

**Example** (mean = 8)

| xᵢ | Deviation (xᵢ − μ) |
|---|---|
| 6 | 6 − 8 = **−2** |
| 10 | 10 − 8 = **+2** |

A negative deviation means the value is below average; positive means above average.

---

## 4. Why Square the Deviations?

If you try to average the raw deviations to measure "spread", they cancel out:

Data: `6, 7, 8, 9, 10` → deviations: `-2, -1, 0, 1, 2`

$$-2 + (-1) + 0 + 1 + 2 = 0$$

Every dataset's deviations sum to zero around its own mean — so this tells us nothing about spread.

**Fix: square each deviation** so negatives become positive:

| Deviation | Squared |
|---|---|
| −2 | 4 |
| −1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

Now we can average these meaningfully → that average is the **variance**.

---

## 5. Variance (σ²)

Variance is the **average of the squared deviations** from the mean. It tells you how spread out the data is, but in *squared* units (which makes it hard to interpret directly — that's what standard deviation fixes).

**Formula (population variance):**

$$\sigma^2 = \frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2$$

**Step-by-step example**

Data: `6, 7, 8, 9, 10`, mean μ = 8

| xᵢ | xᵢ − μ | (xᵢ − μ)² |
|---|---|---|
| 6 | −2 | 4 |
| 7 | −1 | 1 |
| 8 | 0 | 0 |
| 9 | 1 | 1 |
| 10 | 2 | 4 |

Sum of squared deviations = 4+1+0+1+4 = **10**
N = 5

$$\sigma^2 = \frac{10}{5} = 2$$

**Variance = 2**

---

## 6. Standard Deviation (σ)

Standard deviation is simply the **square root of variance**. Taking the square root brings the units back to the original scale, so it's much easier to interpret than variance.

**Formula:**

$$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2} = \sqrt{\text{Variance}}$$

**From the example above:**

$$\sigma = \sqrt{2} \approx 1.41$$

So for the dataset `6, 7, 8, 9, 10`:
- Mean = 8
- Variance = 2
- Standard deviation ≈ 1.41

**Remember:** Mean = center. Standard deviation = spread around that center.

---

## 7. Small vs Large Standard Deviation

Two datasets can have the **same mean** but very different spreads.

**Dataset A:** `7, 8, 8, 8, 9` → mean = 8, values are close together → **small SD**

**Dataset B:** `2, 5, 8, 11, 14` → mean = 8, values are far apart → **large SD**

| SD size | Meaning |
|---|---|
| Small | Values cluster tightly around the mean |
| Large | Values are widely spread out |

---

## 8. Summary Table

| Concept | Symbol | Meaning |
|---|---|---|
| Mean | μ | Center / average of the data |
| Deviation | xᵢ − μ | Distance of one value from the mean |
| Variance | σ² | Average of the squared deviations |
| Standard deviation | σ | √variance; measures spread in original units |

**Flow:**
```
Mean               → Where is the center?
Deviation          → How far is ONE value from the center?
Variance           → What is the average squared distance?
Standard deviation → How spread out is the data overall?
```

---

## 9. Symbols Cheat Sheet

| Symbol | Meaning |
|---|---|
| μ (mu) | Population mean |
| σ (sigma) | Population standard deviation |
| σ² | Population variance |
| xᵢ | An individual value |
| x̄ | Sample mean |
| s | Sample standard deviation |

Note: for a **sample** (a subset of a larger population), the variance formula divides by `(n − 1)` instead of `n` — this is called Bessel's correction and gives an unbiased estimate. Pandas' `.std()` and `.var()` use `n − 1` by default (`ddof=1`), while `.mean()` obviously has no such distinction.

---

## 11. Why This Matters for ML (Beyond EDA)

- **Feature scaling / standardization**: Many algorithms (KNN, SVM, gradient descent-based models, PCA) perform better when features are standardized using:
  $$z = \frac{x - \mu}{\sigma}$$
  This centers data at 0 with unit variance, so features with different scales don't unfairly dominate.
- **Outlier detection**: Points many standard deviations away from the mean (e.g., beyond ±3σ) are often flagged as outliers.
- **Model evaluation**: Metrics like variance of residuals help you judge how consistent a model's errors are.
- **Understanding variance in the bias-variance tradeoff**: "Variance" of a model (how much predictions change with different training data) borrows the same core idea — spread — applied to model behavior instead of raw data.

## 12. Quick Revision

```
mean (μ)             → average / center
xᵢ                    → one individual value
xᵢ − μ                → deviation of one value from the mean
variance (σ²)         → average squared deviation
standard deviation (σ)→ √variance → measures spread
small σ               → values are close together
large σ               → values are spread out
```

**One sentence to remember:**
Mean tells you where the data is centered; standard deviation tells you how spread out the data is around that center.
