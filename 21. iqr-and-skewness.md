# IQR and Skewness — Beginner Notes

## 1. What is IQR?

**IQR** stands for **Interquartile Range**.

It tells us how spread out the **middle 50% of the data** is.

The formula is:

```
IQR = Q3 - Q1
```

Where:
- Q1 = First Quartile (25th percentile)
- Q3 = Third Quartile (75th percentile)

The data between Q1 and Q3 contains the middle 50% of the observations.

## 2. Understanding Quartiles

Quartiles divide sorted data into four parts.

```
0%          25%          50%          75%          100%
|------------|------------|------------|------------|
             Q1         Median         Q3
```

- 25% of the data is below Q1.
- 50% of the data is below the median.
- 75% of the data is below Q3.
- The middle 50% is between Q1 and Q3.

## 3. Finding IQR — Example with 5 Values

Consider:

```
20, 25, 30, 35, 40
```

The data is already sorted.

**Step 1: Find the median**

The middle value is:

```
30
```

**Step 2: Find Q1**

Take the lower half, excluding the median:

```
20, 25
```

The median of these two values is:

```
Q1 = (20 + 25) / 2
   = 22.5
```

**Step 3: Find Q3**

Take the upper half, excluding the median:

```
35, 40
```

Therefore:

```
Q3 = (35 + 40) / 2
   = 37.5
```

**Step 4: Calculate IQR**

```
IQR = Q3 - Q1
    = 37.5 - 22.5
    = 15
```

Therefore:

```
IQR = 15
```

**What does "15 units" mean?**

It means that the distance from Q1 to Q3 is 15 units.

```
Q1                         Q3
22.5 ---------------------- 37.5
          Middle 50%

Distance = 37.5 - 22.5 = 15
```

It does **not** mean that every value differs by 15.

It means:

> The middle 50% of the data occupies a range of 15 units.

If the values represented salaries, an IQR of ₹15,000 would mean the middle 50% of salaries spans ₹15,000 from Q1 to Q3.

## 4. IQR with 6 Values

Consider:

```
10, 20, 30, 40, 50, 60
```

There are 6 values.

**Median**

The two middle values are 30 and 40:

```
Median = (30 + 40) / 2
       = 35
```

**Q1**

Lower half:

```
10, 20, 30
```

So:

```
Q1 = 20
```

**Q3**

Upper half:

```
40, 50, 60
```

So:

```
Q3 = 50
```

**IQR**

```
IQR = Q3 - Q1
    = 50 - 20
    = 30
```

Therefore:

```
IQR = 30
```

## 5. What Does IQR Tell Us?

IQR tells us about the spread of the middle 50%.

**Small IQR**

```
20, 21, 22, 23, 24
```

The values are close together, so the IQR is relatively small.

**Large IQR**

```
10, 20, 30, 40, 50
```

The values are more spread out, so the IQR is larger.

Therefore:

- Small IQR → middle 50% is tightly grouped
- Large IQR → middle 50% is more spread out

## 6. IQR vs Range

The range is:

```
Range = Maximum - Minimum
```

For:

```
10, 20, 30, 40, 50
```

Range:

```
50 - 10 = 40
```

IQR focuses on the middle 50%, while range uses the minimum and maximum. This matters when there are outliers.

## 7. Why IQR Is Useful with Outliers

Consider:

```
10, 20, 30, 40, 50, 1000
```

The value 1000 is very far from the other values.

The range becomes:

```
1000 - 10 = 990
```

So the range makes the data look extremely spread out.

IQR is less affected by this extreme value because it focuses on the middle part of the data. This is one reason IQR is useful for skewed data and outlier detection.

## 8. IQR and Boxplots

A boxplot shows Q1, median, Q3, and possible outliers.

```
       Q1       Median        Q3
        ↓          ↓           ↓
        |----------|-----------|
             THE BOX
        <---------------->
               IQR
```

The box extends from Q1 to Q3.

Therefore:

```
Box length = IQR
```

The line inside the box represents the median. A boxplot can also show values that are unusually far away from the main data.

## 9. Outlier Detection Using IQR

A common rule is the **1.5 × IQR rule**.

First calculate:

```
IQR = Q3 - Q1
```

Then:

```
Lower Bound = Q1 - 1.5 × IQR
Upper Bound = Q3 + 1.5 × IQR
```

Values below the lower bound or above the upper bound are commonly treated as potential outliers.

**Example**

Suppose:

```
Q1 = 25
Q3 = 65
```

Then:

```
IQR = 65 - 25
    = 40
```

Calculate the lower bound:

```
25 - (1.5 × 40)
= 25 - 60
= -35
```

Calculate the upper bound:

```
65 + (1.5 × 40)
= 65 + 60
= 125
```

So:

```
Lower Bound = -35
Upper Bound = 125
```

Any value below -35 or above 125 would be considered a potential outlier using this rule.

## 10. What Is Skewness?

Skewness describes the shape/asymmetry of a distribution.

In simple terms:

> Skewness tells us whether the data has a longer tail toward the left or right.

A perfectly balanced distribution looks roughly like:

```
             /\
            /  \
           /    \
          /      \
_________/        \________
```

The left and right sides are approximately balanced.

## 11. Why Does Skewness Happen?

Real-world data is often not perfectly balanced.

For example, consider salaries:

```
20k, 22k, 25k, 27k, 30k, 35k, 40k, 300k
```

Most people have salaries around 20k–40k, but one person has 300k. That creates a long tail on the right. This is called **right-skewed** or **positively skewed** data.

## 12. Right Skew / Positive Skew

In right-skewed data, the long tail extends toward larger values.

```
Frequency
   |
   |       /\
   |      /  \
   |     /    \
   |____/      \________________
   |                         \
   |                          \
   +--------------------------------> Value
```

The tail points toward the right.

Example:

```
20, 22, 25, 27, 30, 35, 40, 300
```

The value 300 pulls the mean toward the right.

Usually:

```
Mean > Median
```

For strongly right-skewed data, the mean is often noticeably greater than the median.

## 13. Left Skew / Negative Skew

In left-skewed data, the long tail extends toward smaller values.

```
Frequency
   |
   |                 /\
   |                /  \
   |               /    \
   |______________/      \____
   |        /
   |       /
   +--------------------------------> Value
```

The tail points toward the left.

Example:

```
1, 60, 65, 68, 70, 72, 75, 78
```

The value 1 creates a long left tail.

Usually:

```
Mean < Median
```

## 14. No / Very Little Skew

If the data is approximately balanced on both sides, it has little or no skew.

For example:

```
10, 20, 30, 40, 50
```

The values are reasonably balanced around the center.

A roughly symmetric distribution may look like:

```
             /\
            /  \
           /    \
          /      \
_________/        \________
```

In a symmetric distribution:

```
Mean ≈ Median
```

## 15. Important: Real Data Is Rarely Perfect

Real-world data usually isn't perfectly shaped like a textbook diagram.

For example, a distribution might be:

```
        /\
       /  \
      /    \____
_____/          \________
```

It may have only a small amount of skew.

So instead of thinking there are only three possibilities (no skew / right skew / left skew), think of skewness as a continuum:

```
Left skew  <--------- Symmetric --------->  Right skew
```

Some data is strongly skewed, while some is only slightly skewed.

## 16. Relationship Between Mean, Median and Skewness

A useful beginner rule is:

**Right-skewed**

```
Mean > Median
```

Example:

```
20, 22, 25, 27, 30, 35, 40, 300
```

The large value pulls the mean to the right.

**Left-skewed**

```
Mean < Median
```

Example:

```
1, 60, 65, 68, 70, 72, 75, 78
```

The small value pulls the mean to the left.

**Approximately symmetric**

```
Mean ≈ Median
```

## 17. Why Median Is Useful for Skewed Data

Consider:

```
20k, 25k, 30k, 35k, 500k
```

**Mean:**

```
(20 + 25 + 30 + 35 + 500) / 5
= 122k
```

**Median:**

```
30k
```

The mean is heavily affected by the 500k value. The median is much less affected.

So for strongly skewed data, the median can be a more representative measure of the center.

## 18. IQR and Skewness Together

IQR and skewness answer different questions.

**IQR**

> How spread out is the middle 50%?

```
IQR = Q3 - Q1
```

**Skewness**

> Is the distribution stretched more toward the left or right?

```
Left tail  ← distribution →  Right tail
```

So:

- IQR → Spread of middle 50%
- Skewness → Shape/asymmetry of distribution

## 19. Quick Example

Suppose customer spending is:

```
100, 120, 130, 150, 170, 200, 250, 1000
```

The value 1000 creates a long right tail. Therefore, the data is right-skewed.

For the middle 50%, calculate Q1 and Q3 and then:

```
IQR = Q3 - Q1
```

The IQR tells us how spread out the central group of customers is, while skewness tells us that the distribution has a longer tail toward high spending values.

## 20. Quick Cheat Sheet

| Concept | Meaning |
|---|---|
| Mean | Sum of values ÷ number of values |
| Median | Middle value after sorting |
| Q1 | 25th percentile |
| Q3 | 75th percentile |
| IQR | Q3 − Q1 |
| IQR meaning | Spread of middle 50% |
| Range | Maximum − Minimum |
| Skewness | Asymmetry of a distribution |
| Right skew | Long tail toward larger values |
| Left skew | Long tail toward smaller values |
| Symmetric | Both sides are approximately balanced |
| Right skew | Usually Mean > Median |
| Left skew | Usually Mean < Median |
| Symmetric | Usually Mean ≈ Median |

## 21. Easy Way to Remember

- **MEAN** → Average
- **MEDIAN** → Middle
- **Q1** → 25%
- **Q3** → 75%
- **IQR** → Q3 - Q1 → Middle 50% spread
- **SKEWNESS** → Which direction does the tail stretch?

The most important idea:

> IQR tells you how spread out the middle 50% is, while skewness tells you whether the distribution is stretched more toward the left or right.
