# Reading JSON and SQL Data into Pandas

Notes and code examples for loading data from JSON files/URLs and from a SQL
database (MySQL) into a pandas DataFrame.

---

## 1. Reading JSON data

JSON (JavaScript Object Notation) is a lightweight, near-universal data
format — most languages (Python, JS, Java, etc.) can parse it, and it's the
most common response format for web APIs.

### From a local file

```python
import pandas as pd

df = pd.read_json("recipes.json")
print(df.shape)   # e.g. (3900, 3) -> id, cuisine, ingredients
df.head()
```

Useful `read_json` options (check the [pandas docs](https://pandas.pydata.org/docs/reference/api/pandas.read_json.html)
for the full list):

| Option | Purpose |
|---|---|
| `orient` | Tells pandas how the JSON is structured (records, columns, split, etc.) |
| `encoding` | Change if you hit a `UnicodeDecodeError` on the default encoding |
| `lines=True` | Use when the file is JSON Lines (one JSON object per line) |
| `chunksize` | Read a large file in chunks instead of loading it all into RAM |

### From a URL

`read_json` can pull directly from a URL — no manual download needed:

```python
url = "https://api.exchangerate-api.com/v4/latest/USD"
df = pd.read_json(url)
df.head()
```

This is handy for things like currency-exchange-rate APIs, where the
response is already valid JSON and you just want it in a DataFrame.

## 2. Reading SQL data (MySQL example)

SQL (Structured Query Language) is the standard way relational databases
store and query data. The general workflow to get SQL data into pandas:

1. Load the `.sql` dump into a MySQL server (e.g. via XAMPP + phpMyAdmin).
2. Install a Python↔MySQL bridge library.
3. Open a connection from Python.
4. Use `pandas.read_sql` to run a query and get a DataFrame back.

### Step 1 — Get the data into MySQL

- Install a local server stack such as **XAMPP** (start the *Apache* and
  *MySQL* services from its control panel).
- Open `phpMyAdmin` (`localhost/phpmyadmin`), create a new database (e.g.
  `world`), and use **Import** to load a `.sql` dump file into it. Larger
  dumps just take longer to import.
- You'll end up with normal tables you can browse in phpMyAdmin, e.g. a
  `world` database with `city`, `country`, and `countrylanguage` tables.

### Step 2 — Install the connector library

```bash
pip install mysql-connector
```

### Step 3 — Connect from Python

```python
import mysql.connector

conn = mysql.connector.connect(
    host="localhost",     # or the remote server's IP/hostname
    user="root",           # default MySQL user for a local dev setup
    password="",           # set if your server requires one
    database="world"
)
```

### Step 4 — Query into a DataFrame

`pandas.read_sql(query, connection)` takes any SQL string and the open
connection object, and returns a DataFrame:

```python
query = "SELECT * FROM city"
df = pd.read_sql(query, conn)
df.head()
```

Because it's just a SQL string, you can filter, select specific columns,
or apply conditions the normal SQL way:

```python
# Only cities in India
df_india = pd.read_sql("SELECT * FROM city WHERE CountryCode = 'IND'", conn)

# Only country + name columns
df_names = pd.read_sql("SELECT Name, Continent FROM country", conn)

# Countries with life expectancy above 60
df_le = pd.read_sql(
    "SELECT * FROM country WHERE LifeExpectancy > 60", conn
)
```

### Useful `read_sql` options

- Pass a full query string **or** just a table name for a straightforward
  `SELECT *`.
- `index_col` — set a column as the DataFrame's index.
- `chunksize` — stream large result sets in chunks instead of loading
  everything into memory at once.

---

## Summary

| Source | Function | Key inputs |
|---|---|---|
| Local/remote JSON | `pd.read_json(path_or_url)` | file path or URL |
| SQL database | `pd.read_sql(query, connection)` | SQL string + a DB connection object |

Both return a standard pandas DataFrame, so once the data is loaded, all
the usual pandas operations (filtering, cleaning, merging, etc.) work the
same way regardless of where the data originally came from.
